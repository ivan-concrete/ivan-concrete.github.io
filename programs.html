Список доступных программ

1. HTML Studio

Гениальный в своей простоте HTML-редактор. Включает панели инструментов для быстрой вставки тегов (текст, формы, медиа), менеджер файлов проекта и встроенный режим Live View для мгновенного просмотра результата верстки.

2. LUZ Manager

Консольный файловый менеджер (проводник), созданный в лучших традициях классического FAR Manager. Быстрая двухпанельная навигация, кастомная подсветка расширений файлов, управление каталогами без мыши и высокая производительность.

3. LUZ Pad

Просто текстовый редактор. Идеально для быстрых заметок, а главное- без такой же програмы мало кто сможет прочитать ваш файл.
